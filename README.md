# DANSK PÅ ARBEJDE

A private interactive website-book of practical workplace Danish for Ukrainian speakers. Created by Anna Melnykova.

## Status

**Stage 1 is the style prototype** (`prototype/index.html`). It shows five visual variants of the same sample content. Switch between them with the bar at the bottom or the ← → keys, and press **Обрати цей ✓** to copy your choice.

Open it locally by double-clicking `prototype/index.html`, or view it on GitHub Pages:
https://sevastian-bahynskyi.github.io/danish-book-anna/

Direct links: `#cream`, `#nordic`, `#peony`, `#hygge`, `#glass`.

**Stage 2** is the full app (Expo / React Native Web + Supabase). It will be built in the chosen style.
